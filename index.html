Tujuan Pembelajaran

Setelah menggunakan media ini, peserta didik mampu:

  1. Mengakses router MikroTik melalui Winbox (MAC address) dan Terminal.
  2. Mengonfigurasi router sebagai gateway internet: DHCP Client di WAN, IP address LAN, default route, DNS, NAT masquerade, dan DHCP Server.
  3. Mengatur pembagian bandwidth klien menggunakan Simple Queue.
  4. Menerapkan Firewall Filter dan address-list untuk memblokir situs serta melindungi router.
  5. Membangun layanan Hotspot dengan autentikasi user dan user profile.
  6. Menguji dan mendiagnosis koneksi dari sisi klien (ipconfig, ping, nslookup, tracert).

Materi 1

Mengenal MikroTik dan cara mengaksesnya

MikroTik adalah produsen perangkat jaringan asal Latvia. Produknya terdiri dari RouterOS (sistem operasi router) dan RouterBOARD (perangkat keras), misalnya RB951Ui-2HnD yang dipakai di simulasi ini. RouterOS juga bisa dipasang di PC biasa sehingga PC berfungsi sebagai router.

Cara aksesPortKeterangan
WinboxTCP 8291Aplikasi GUI. Bisa terhubung lewat MAC address walaupun router belum punya IP.
WebFigTCP 80Konfigurasi lewat browser ke IP router.
TerminalSSH 22 · Telnet 23Baris perintah (CLI). Tersedia juga lewat menu New Terminal di Winbox.
APITCP 8728Dipakai aplikasi pihak ketiga, misalnya aplikasi billing hotspot.
Login bawaan. Pada RouterOS v6, user admin dengan password kosong. Beberapa perangkat keluaran baru memakai password acak yang tercetak di stiker perangkat. Router di lab ini dalam keadaan kosong (No Default Configuration), jadi belum ada IP sama sekali.

Materi 2

Router sebagai gateway internet

Agar komputer di lab bisa mengakses internet melalui router, ada enam komponen yang harus lengkap. Satu saja terlewat, internet tidak jalan. Di lab ini modem ISP membagikan IP lewat DHCP, sehingga IP WAN, default route, dan DNS ISP didapat sekaligus dari DHCP Client.

KomponenContoh di labFungsinya
IP WANDHCP Client di ether1 → akan mendapatkan alamat IP otomatis dari ISPRouter meminta IP dari modem ISP secara otomatis. Status harus bound.
IP LAN192.168.10.1/24 di ether2Menjadi gateway bagi PC di lab.
Default route0.0.0.0/0 → 192.168.1.1 (dinamis, flag DAS)Dibuat otomatis oleh DHCP Client (Add Default Route = yes). Mengarahkan semua tujuan yang tidak dikenal ke ISP.
DNSDNS dari ISP (otomatis) + 8.8.8.8, 8.8.4.4 + allow-remote-requestsMenerjemahkan nama domain menjadi IP. Dengan allow-remote-requests, router juga melayani DNS klien.
NAT masqueradechain srcnat, out-interface ether1Mengganti IP sumber klien dengan IP WAN router agar balasan dari internet bisa kembali.
DHCP Serverpool 192.168.10.2–192.168.10.254Membagikan IP, subnet mask, gateway, dan DNS ke klien secara otomatis.

Diagnosis cepat dari PC klien

  • IP 169.254.x.x (APIPA) → DHCP Server belum aktif atau bermasalah.
  • ping 192.168.10.1 gagal → IP LAN router atau gateway klien salah.
  • ping 8.8.8.8 gagal → periksa status DHCP Client (harus bound), default route, dan NAT.
  • ping 8.8.8.8 berhasil tetapi ping google.com gagal → masalah DNS.
  • tracert google.com menunjukkan di hop ke berapa paket berhenti.

Materi 3

Membaca perintah CLI RouterOS

Perintah RouterOS tersusun seperti alamat folder: /menu submenu perintah parameter=nilai. Garis miring di depan berarti mulai dari menu utama (root).

[admin@MikroTik] > /ip address add address=192.168.10.1/24 interface=ether2 [admin@MikroTik] > /ip address print Flags: X - disabled, I - invalid, D - dynamic # ADDRESS NETWORK INTERFACE 0 192.168.10.1/24 192.168.10.0 ether2 [admin@MikroTik] > /ip address [admin@MikroTik] /ip address> remove 0 # nomor diambil dari hasil print
  • Tab melengkapi nama menu atau parameter. Tekan dua kali untuk melihat pilihan.
  • ? menampilkan bantuan: daftar submenu, perintah, atau parameter.
  • print menampilkan isi menu; set, remove, enable, disable memakai nomor dari hasil print.
  • .. naik satu menu, / kembali ke root.
  • /export menampilkan seluruh konfigurasi dalam bentuk script.
  • Ctrl+C menghentikan perintah yang berjalan terus, misalnya ping tanpa count.

Materi 4

DHCP Server

DHCP membagikan konfigurasi IP secara otomatis lewat empat tahap yang disebut DORA:

  1. DiscoverKlien mencari server DHCP (broadcast)
  2. OfferServer menawarkan IP dari pool
  3. RequestKlien meminta IP yang ditawarkan
  4. AcknowledgeServer mengesahkan, lease tercatat
BagianMenuIsi
Pool/ip poolRentang alamat yang boleh dibagikan.
DHCP Server/ip dhcp-serverInterface tempat server berjalan, pool, lease time.
Network/ip dhcp-server networkGateway dan DNS yang diberikan ke klien.
Leases/ip dhcp-server leaseDaftar klien yang sudah mendapat IP. Tanda D = dinamis; Make Static mengunci IP klien.
Tips. Wizard DHCP Setup membuat pool, server, dan network sekaligus dalam keadaan aktif. DHCP Server yang ditambah manual lewat add secara bawaan berstatus disabled, jadi perlu di-enable. RouterOS membagikan IP mulai dari alamat tertinggi pool, sehingga klien pertama biasanya mendapat .254.

Materi 5

Simple Queue

Simple Queue membatasi kecepatan berdasarkan target (IP, subnet, atau interface). Parameter utamanya max-limit=upload/download dilihat dari sisi klien. Satuan k = kilobit per detik, M = megabit per detik.

/queue simple add name=PC-01 target=192.168.10.254/32 max-limit=1M/2M /queue simple add name=Jaringan-LAN target=192.168.10.0/24 max-limit=5M/10M
Urutan penting. Simple queue diperiksa dari atas ke bawah dan berhenti di queue pertama yang cocok. Queue khusus satu klien harus berada di atas queue seluruh jaringan. Pindahkan dengan move di CLI atau geser baris di Winbox.

Materi 6

Firewall Filter

Firewall Filter memutuskan paket diterima atau dibuang. Setiap rule berada pada sebuah chain:

ChainPaket yang diprosesContoh
inputPaket yang tujuannya router itu sendiriPing ke router, akses Winbox, permintaan DNS ke router
forwardPaket yang melewati routerPC lab membuka situs di internet
outputPaket yang dibuat routerRouter melakukan ping ke google.com
ActionAkibatnya
acceptPaket diizinkan, pemeriksaan berhenti.
dropPaket dibuang diam-diam; pengirim mengalami timeout.
rejectPaket dibuang dan pengirim diberi pesan ICMP “unreachable”.

Address-list mengelompokkan banyak alamat (IP, subnet, atau nama domain) dalam satu nama. Satu rule cukup merujuk nama list tersebut.

/ip firewall address-list add list=situs-terlarang address=gameseru.id /ip firewall filter add chain=forward dst-address-list=situs-terlarang action=drop /ip firewall filter add chain=input protocol=icmp src-address=192.168.10.253 action=drop
Ingat. Rule dibaca dari atas. Kolom Bytes dan Packets bertambah saat rule cocok, sehingga bisa dipakai untuk membuktikan rule bekerja.

Materi 7

Hotspot

Hotspot (captive portal) memaksa pengguna login sebelum bisa memakai internet. Saat membuka situs apa pun, browser dialihkan ke halaman login router.

BagianFungsinya
ServerHotspot yang berjalan di interface tertentu (misal ether3).
Server ProfilePengaturan server, termasuk dns-name halaman login dan hotspot-address.
UsersAkun login (name, password, profile).
User Profilesshared-users = jumlah perangkat per akun; rate-limit = rx/tx, yaitu upload/download klien.
ActiveDaftar pengguna yang sedang login.

Pertanyaan wizard /ip hotspot setup

  1. hotspot interface — interface tempat hotspot (ether3)
  2. local address of network — IP router di jaringan hotspot
  3. masquerade network — buat NAT untuk jaringan hotspot (yes)
  4. address pool of network — rentang IP untuk klien hotspot
  5. select certificate — none
  6. ip address of smtp server — 0.0.0.0
  7. dns servers — DNS untuk router
  8. dns name — nama halaman login, misalnya login.tkj.net
  9. name & password of local hotspot user — akun awal
